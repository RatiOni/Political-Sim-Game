# The Pixel Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dashboard map with the approved DOS-style 2D pixel map of Ardenia, built from the baked data, whose tiles visibly change as regions grow, develop and fall into trouble.

**Architecture:** A one-time `TileBaker` classifies the baked height and region rasters into a 168×100 grid of terrain kinds (`tiles.json`). `TileArt` builds one tile atlas: palette-generated ground tiles plus CC0 Kenney sprites recoloured to the 32-colour `MapPalette`. `ArdeniaMap` keeps its public API but draws through `TileMapLayer`s (terrain, growth overlay, lines), with pixel-font labels. Pure `GrowthLayers` functions turn each region snapshot into tile targets, which the map applies in a short staggered flip each month.

**Tech Stack:** Godot 4.7.2, statically typed GDScript, the `gl_compatibility` renderer, `TileMapLayer`, nearest-neighbour filtering, Kenney CC0 (Micro Roguelike 8×8, 1-Bit Pack 16×16, Kenney Fonts), and the project's headless harness `res://scripts/native/testing/test_support.gd`.

**Spec:** `docs/superpowers/specs/2026-10-28-pixel-map-design.md` (the approved mockup is `.scratch/pixel_mock.html`; the throwaway renderer that made it is `godot/tools/_mock_pixel.gd`, and its tile and classification rules are the reference look).

- Grid `168 × 100`, tile `8 × 8` px, native image `1344 × 800`. Pixels are never blurred: `TEXTURE_FILTER_NEAREST`, and the map scales by integer factors where possible.
- One palette, `MapPalette.DAY`: 32 colours, with `MapPalette.DUSK` derived from it. No colour on the map comes from anywhere else.

- Assets come only from the verified CC0 Kenney packs, already downloaded to `.scratch/downloads/kenney2d/`: `kenney_micro-roguelike`, `kenney_1-bit-pack`, `kenney_fonts`. `godot/assets/CREDITS.md` lists each one.

- Produces:

  - `GrowthLayers.targets(row: Dictionary, geo: MapGeometry, tiles: Dictionary) -> Dictionary`, giving `{"town_cells": [...], "lit_cells": [...], "farm_cells": [...], "fallow_cells": [...]}` for one region.
